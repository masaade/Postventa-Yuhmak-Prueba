YUHMAK HOGAR V62 - STREAMLIT CLOUD
1. Crear repositorio PRIVADO en github.com/new.
2. Subir app.py, administracion.py, executive_ui.py, requirements.txt y .gitignore.
3. Abrir https://share.streamlit.io/ y elegir Create app / Deploy.
4. Seleccionar repositorio, rama main y archivo app.py.
5. Esperar el despliegue y copiar URL generada.
IMPORTANTE: la app NO tiene autenticacion propia. No subir Excel reales ni informacion confidencial.
Streamlit Community Cloud puede tener limitaciones de visibilidad/acceso segun configuracion y plan.
Los datos cargados en el servidor no son persistencia empresarial confiable.
Para uso real: configurar control de acceso, almacenamiento persistente y respaldos.
